# 2. Интерфейс приложения
## 2.1. Главное окно приложения: 

![Рис. 2. Общий вид загруженной таблицы](images/Obchij_vid.png)

Пространство главного окна логически разделено на пять полей:<br>
1 – Главное меню программы;<br>
2 – Каталог устройств;<br> 
3 – Таблица редактирования уставок параметров устройства;<br> 
4 – Панель дополнительной информации об устройстве;<br> 
5 – Панель параметров связи;<br>

##  2.2. Меню кнопки "Обновить список устройств"

![Рис. 3. Меню кнопки обновить](images/Menu_Obnovit.png)

- Обновляет список устрйств и отслеживает изменения в загруженных ini файлах;<br>
- Выстраивает устройства по номерам;<br>
- Выстраивает устройства по месту установки;<br>
- Выстраивает устройства по типу механизма;<br>
- Выстраивает устройства по дате последнего обслуживания;<br>
- Выстраивает устройства по типу;<br>
