1. Общие сведения

1.1. Назначение

Программа Ajuster – это универсальный набор средств, позволяющий эффективно работать с устройствами оснащёнными асинхронным последовательным интерфейсом поддерживающими протоколы передачи данных ModBus RTU и ModBus RTU over TCP/IP.

1.2 Выполняемые функции

Поддержка протоколов ModBus RTU и ModBus RTU over TCP/IP;

Ведение базы оборудования и его уставок

База хранит следующую информацию об устройстве:
- краткая информация о механизме и месте установки оборудования;
- уставки параметров;
- дата последнего обслуживания;

Копирование параметров из базы в блок, и обратно;

«Клонирование» блоков, для создания резерва оборудования (блоков с идентичными параметрами)

Осциллографирование/запись параметров

Возможности анализа:

  • Масштабирование развёртки по времени;
  • Измерение величины сигналов в выбранной точке;
  • Измерение интервалов времени между событиями;
  • Совмещение в одних координатах до 5 графиков;

Запись осциллограмм для последующего анализа с теми же возможностями;

Запись .csv файлов мгновенного состояния секции [RAM] Modbus регистров контроллера

Запись .xlsx файлов для записи состояния секций [Flash] и [CD] Modbus регистров контроллера

1.3 Минимальные системные требования и инсталляция

  • Ajuster не требует специальной инсталляции, для работы просто откройте в браузере ссылку, указанную в документации.

Минимальные системные требования:

  • Для работы по USB (COM-порт):

  • Операционная система: Windows: Windows 10 или новее.
    Linux: Любой современный дистрибутив (например, Ubuntu 20.04 LTS, Debian 11, Astra Linux или РЕД ОС), поддерживающий установку браузера Chromium.
    macOS: macOS 10.15 (Catalina) или новее.

  • Браузер: Google Chrome, Microsoft Edge, Яндекс.Браузер или Opera версии 89 или выше (выпущены после марта 2021 г.).

    • Для работы по сети (Ethernet / Wi-Fi через Modbus TCP/IP):

  • Операционная система: Любая, включая Windows, macOS, Linux, Android (версии 10+) и iOS (версии 15+).

  • Браузер: Любой современный браузер с поддержкой стандартов HTML5 и WebGL (Chrome, Safari, Firefox, Edge и их мобильные версии).

  • Аппаратные требования (минимальные):

  • Процессор: Двухъядерный процессор (Intel Core i3 / AMD Ryzen 3 или аналогичный ARM-процессор в планшетах).

  • Оперативная память: 4 ГБ.

  • Видеокарта: Любая с поддержкой аппаратного ускорения WebGL.
